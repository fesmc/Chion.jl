Default Parameters

Default values of the multilayer model (BESSIModel) and the bulk models (PDDModel, ITMModel). Scheme and layer settings are BESSIModel keywords. The physical constants are forwarded to SnowpackPhysicalConstants and can be overridden through the same model keywords, for example BESSIModel(grid; semix_sensible_exchange_factor=2.5, alpha_dry=0.87). The current values of a model are in model.c.

The surface-energy-balance defaults were calibrated for the Greenland ice sheet against MAR v3.14.3 (1980–1989).
