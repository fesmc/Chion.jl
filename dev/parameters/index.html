Parameters

All physical constants and scheme choices of a BESSIModel are fields of one immutable struct, Params; the bulk models take PDDParams and ITMParams. The vertical discretisation of the columns is not a parameter but part of the grid, Layering (see Models And Coupling).

Every exchangeable process is a scheme slot of Params that takes an instance of a scheme type, and the instance carries the coefficients of that scheme. Constants shared by several schemes (the dry, wet and ice albedos, the emissivities, the material constants) stay flat fields of Params:

params = Params(;
    NF = Float32,                                           # number type of the model
    albedo_scheme = AgingAlbedo(cold_timescale_days = 15),  # scheme with a coefficient
    turbulent_flux_scheme = SemixTurbulentFluxes(sensible_exchange_factor = 2.5),
    diurnal_cycle = DiurnalSubsteps(max_substeps = 4,
        temperature_cycle = NoDiurnalTemperatureCycle()),
    alpha_dry = 0.84,                                       # shared constant
)
model = BESSIModel(grid; forcing, params)
model.alpha_dry, model.albedo_scheme                        # forwarded to model.params

Params(params; kwargs...) replaces single fields of an existing Params. Unknown keywords throw an error that lists the fields. Every number and the floating-point coefficients of the schemes are converted to NF.

The defaults are the Greenland calibration against MAR v3.14.3 with daily forcing (1980–1989 for the surface energy balance). They are a regression contract: the paper runs depend on them.

Kinks

Params(kinks = SmoothKinks(flux, wind, fraction)) smooths the kinks that the state crosses (the bare-ice melt flux max(Q, 0), the wind-speed floor of the SEMIX fluxes, the clamp of the cloud proxy's shortwave deficit) over a band of half-width ε per quantity, for smoother gradients in calibration; the default ExactKinks() keeps them exact (bit-identical).

Chion.AbstractKinks — Type

Abstract supertype of how the model treats its kinks, the switches of max, min and clamp. Pass an instance as Params(kinks = …): ExactKinks (the default) or SmoothKinks.

The kinks make the model piecewise smooth: a derivative exists almost everywhere but jumps where a switch flips, and gradient-based calibration can stall there. Discrete events (layer split and merge, snow ↔ bare ice) are not kinks in this sense and stay as they are.

source
Chion.ExactKinks — Type
struct ExactKinks <: Chion.AbstractKinks

Every max, min and clamp as it is (the default): bit-identical to a model without a kink treatment.

source
Chion.SmoothKinks — Type
struct SmoothKinks{NF<:Real} <: Chion.AbstractKinks

Smooth the kinks over a band of half-width ε, one ε per physical quantity: max(x, 0) becomes the C¹ quadratic blend (x + ε)² / 4ε for |x| < ε and is exact outside the band; max(a, b), min(a, b) and clamp follow from it. An ε of zero keeps that group exact.

εwhere
flux (W m⁻²)melt energy of bare ice, max(Q_net, 0)
wind (m s⁻¹)floor of the wind speed (0.1 m s⁻¹) of the SEMIX turbulent fluxes
fraction (–)clamp of the shortwave deficit of the cloud-proxy longwave to [0, 1]

Not smoothed are bounds that the state sits on rather than crosses, where a blend would bias every step by about ε/4 (albedo at alpha_wet/alpha_dry, temperatures clamped to T₀), and the power of the cloud fraction at zero.

Fields

  • flux::Real = 1.0: half-width for heat fluxes (W m⁻², default 1)

  • wind::Real = 0.05: half-width for wind speeds (m s⁻¹, default 0.05)

  • fraction::Real = 0.01: half-width for fractions (–, default 0.01)

Chion.Params — Type
struct Params{NF<:Real, FS<:Chion.AbstractFreshSnowDensityScheme, A<:Chion.AbstractAlbedoScheme, D<:Chion.AbstractDensificationScheme, S<:Chion.AbstractSurfaceEnergyBalanceScheme, T<:Chion.AbstractTurbulentFluxScheme, L<:Chion.AbstractLongwaveScheme, DC<:Chion.AbstractDiurnalCycle, K<:Chion.AbstractKinks}

All physical constants and scheme choices of a BESSIModel, in one immutable, concretely typed struct. Build it with the keyword constructor, which fills in the defaults, the Greenland calibration against MAR v3.14.3 (daily forcing):

julia> params = Params(albedo_scheme = AgingAlbedo(cold_timescale_days = 15), NF = Float32);

julia> params.albedo_scheme
AgingAlbedo(cold_timescale_days = 15.0)

julia> params.alpha_dry
0.81f0

Every scheme slot takes an instance of its abstract type; the instance carries the coefficients of that scheme. ParamsAISv1 gives the Antarctic calibration.

Fields

  • rho_i::Real: ice density (kg m⁻³, default 917)

  • rho_w::Real: liquid water density (kg m⁻³, default 1000)

  • ci::Real: specific heat capacity of ice (J kg⁻¹ K⁻¹, default 2110)

  • cw::Real: specific heat capacity of liquid water (J kg⁻¹ K⁻¹, default 4181)

  • Lm::Real: latent heat of fusion (J kg⁻¹, default 3.34e5)

  • Lv::Real: latent heat of vaporisation (J kg⁻¹, default 2.501e6)

  • cp_air::Real: specific heat capacity of air (J kg⁻¹ K⁻¹, default 1003)

  • σ::Real: Stefan–Boltzmann constant (W m⁻² K⁻⁴, default 5.670373e-8)

  • T0::Real: melting point (K, default 273.15)

  • seconds_per_day::Real: seconds per day (default 86400)

  • ϵ_snow::Real: longwave emissivity of snow (–, default 0.98)

  • eps_ice::Real: longwave emissivity of bare ice (–, default 0.98)

  • ϵ_air::Real: emissivity of a graybody sky, used by GraybodyLongwave (–, default 0.8)

  • alpha_dry::Real: albedo of dry fresh snow (–, default 0.81)

  • alpha_wet::Real: albedo of wet snow (–, default 0.70)

  • alpha_ice::Real: albedo of bare ice (–, default 0.40)

  • max_lwc_albedo::Real: volumetric liquid-water content at which DynamicAlbedo reaches alpha_wet (–, default 0.1)

  • density_init::Real: density of the initial layers (kg m⁻³, default 300)

  • temperature_init::Real: temperature of the initial layers and substrate (K, default 273)

  • refreezing_correction::Real: factor on the refreezing capacity (–, default 1)

  • fresh_snow_density_scheme::Chion.AbstractFreshSnowDensityScheme: density of fresh snow, an AbstractFreshSnowDensityScheme (default ConstantFreshSnowDensity())

  • albedo_scheme::Chion.AbstractAlbedoScheme: snow albedo, an AbstractAlbedoScheme (default DynamicAlbedo())

  • densification_scheme::Chion.AbstractDensificationScheme: densification of low-density snow, an AbstractDensificationScheme (default BESSIDensification())

  • surface_energy_balance_scheme::Chion.AbstractSurfaceEnergyBalanceScheme: longwave exchange of the surface, an AbstractSurfaceEnergyBalanceScheme (default SemixSurfaceEnergyBalance())

  • turbulent_flux_scheme::Chion.AbstractTurbulentFluxScheme: turbulent heat fluxes, an AbstractTurbulentFluxScheme (default SemixTurbulentFluxes())

  • longwave_scheme::Chion.AbstractLongwaveScheme: longwave down where the forcing lacks it, an AbstractLongwaveScheme (default CloudProxyLongwave())

  • diurnal_cycle::Chion.AbstractDiurnalCycle: diurnal cycle within a forcing step, an AbstractDiurnalCycle (default DiurnalSubsteps())

  • kinks::Chion.AbstractKinks: treatment of the kinks (max, min, clamp), an AbstractKinks (default ExactKinks())

Chion.DynamicAlbedo — Type
struct DynamicAlbedo <: Chion.AbstractAlbedoScheme

BESSI snow aging: the albedo decreases by (1.35·10⁻³ (T − T₀) + 0.0278) per day, relaxes toward alpha_wet with the liquid-water content of the surface layer (saturated at max_lwc_albedo), and brightens with snowfall, by (alpha_dry − alpha_wet)(1 − exp(−m_s / 3 kg m⁻²)).

Chion.AgingAlbedo — Type
struct AgingAlbedo{NF<:Real} <: Chion.AbstractAlbedoScheme

Exponential decay from alpha_dry toward alpha_wet with the time since the latest snowfall, α = αwet + (α − αwet) exp(−Δt / τ), with τ the cold or the melting time scale (Oerlemans and Knap, 1998). Snowfall resets the albedo to alpha_dry.

Fields

  • cold_timescale_days::Real = 20.0: e-folding time of the albedo decay of a subfreezing surface (day, default 20)

  • melting_timescale_days::Real = 2.0: e-folding time of the albedo decay of a melting surface (day, default 2)

Chion.SemixTurbulentFluxes — Type
struct SemixTurbulentFluxes{NF<:Real} <: Chion.AbstractTurbulentFluxScheme

SEMIX bulk sensible and latent heat fluxes: a neutral transfer coefficient CH = κ² / (ln(z/z₀ₘ) ln(z/z₀ₕ)) corrected with the bulk Richardson number Ri (1/(1 + b Ri) for stable, √(1 − 16 Ri) for unstable stratification), QH = fH ρ cp CH U (Ta − Ts) and QE = fE L ρ CH U (qa − qs).

  • z0m_ice::Real = 0.01: momentum roughness length of bare ice (m, default 0.01)

  • zm_to_zh::Real = 10.0: ratio of the momentum to the heat roughness length z₀ₘ/z₀ₕ (–, default 10)

  • sensible_exchange_factor::Real = 3.0: factor f_H of the sensible heat flux (–, default 3, the GrIS calibration)

  • stable_coefficient::Real = 40.0: stability coefficient b of stable stratification (–, default 40)

  • latent_exchange_factor::Real = 1.0: factor f_E of the latent heat flux (–, default 1)

Chion.CloudProxyLongwave — Type
struct CloudProxyLongwave{NF<:Real} <: Chion.AbstractLongwaveScheme

Longwave down ε σ Ta⁴ with an effective emissivity weighted between clear sky and overcast, ε = εcs (1 − nᵖ) + εoc nᵖ, both linear in Ta − T₀, and the cloud fraction n diagnosed from the shortwave transmissivity: the clear-sky transmissivity τcs = min(1, τ₀ + τz z + τS ln(SWTOA / 300 W m⁻²)) is reduced by clouds by the factor 1 − a nᵇ exp(−d z) (Konzelmann et al., 1994). Resolved once per daily forcing step; in the polar night and for sub-daily forcing n is night_cloud_fraction.

Fields

  • clear_sky_transmissivity_sea_level::Real = 0.718: clear-sky transmissivity τ₀ at sea level and SW_TOA = 300 W m⁻² (–, default 0.718)

  • clear_sky_transmissivity_insolation::Real = 0.0569: insolation coefficient τ_S of the clear-sky transmissivity (–, default 0.0569)

  • cloud_transmission_coefficient::Real = 0.447: cloud transmission coefficient a (–, default 0.447)

  • cloud_transmission_exponent::Real = 2.75: cloud transmission exponent b (–, default 2.75)

  • cloud_transmission_decay_per_km::Real = 0.225: decay d of the cloud transmission with height (km⁻¹, default 0.225)

  • clear_sky_emissivity::Real = 0.716: clear-sky emissivity at T₀ (–, default 0.716)

  • clear_sky_emissivity_temperature_slope::Real = 0.00239: temperature slope of the clear-sky emissivity (K⁻¹, default 0.00239)

  • overcast_emissivity::Real = 0.952: overcast emissivity at T₀ (–, default 0.952)

  • overcast_emissivity_temperature_slope::Real = 0.00362: temperature slope of the overcast emissivity (K⁻¹, default 0.00362)

  • cloud_emissivity_exponent::Real = 3.0: exponent p of the cloud fraction in the emissivity weight (–, default 3)

  • night_cloud_fraction::Real = 0.85: cloud fraction in the polar night and for sub-daily forcing (–, default 0.85)

  • emissivity_max::Real = 1.0: upper bound of the effective emissivity (–, default 1)

Chion.ITMParams — Type
struct ITMParams{NF<:Real}

Parameters of an ITMModel, the insolation–temperature–melt scheme of the Fortran fesmc/chion/smbpal code: melt M = max(τ(z)(1 − α) S + c + t (T − T₀), 0) / (ρw Lm) with the transmissivity τ = a + b √z and a latitude-dependent offset c.

Fields

  • trans_a::Real: transmissivity at sea level, a (–, default 0.46)

  • trans_b::Real: transmissivity increase with √height, b (m^-½, default 6e-5)

  • itm_c::Real: melt offset c (W m⁻², default -45)

  • itm_t::Real: temperature coefficient t (W m⁻² K⁻¹, default 10)

  • itm_b::Real: latitude slope of the offset (W m⁻² degree⁻¹, default -2)

  • itm_lat0::Real: reference latitude of the offset (degree, default 65; 90 or more disables the slope)

  • H_snow_max::Real: snow water equivalent above which snow becomes ice (mm w.e., default 5000)

  • Pmaxfrac::Real: maximum refrozen fraction of the precipitation (–, default 0.6)

  • H_snow_crit_desert::Real: snow depth of full snow cover on desert (mm w.e., default 10)

  • H_snow_crit_forest::Real: snow depth of full snow cover on forest (mm w.e., default 100)

  • melt_crit::Real: melt rate above which snow counts as wet (mm w.e. day⁻¹, default 0.5)

  • alb_ocean::Real: albedo of the ocean (–, default 0.1)

  • alb_land::Real: albedo of bare land (–, default 0.2)

  • alb_forest::Real: albedo of forest (–, default 0.1)

  • alb_ice::Real: albedo of bare ice (–, default 0.4)

  • alb_snow_dry::Real: albedo of dry snow (–, default 0.8)

  • alb_snow_wet::Real: albedo of wet snow (–, default 0.65)

  • firn_fac::Real: warming of the firn by refreezing (K per mm w.e. day⁻¹, default 0.0266)

  • rho_w::Real: liquid water density (kg m⁻³, default 1000)

  • Lm::Real: latent heat of fusion (J kg⁻¹, default 3.34e5)

  • T0::Real: melting point (K, default 273.15)

  • seconds_per_day::Real: seconds per day (default 86400)
