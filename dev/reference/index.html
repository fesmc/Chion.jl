Advanced Reference

These helpers support advanced workflows that inspect state directly, manage device storage, or inspect timing information. Some are intentionally module-qualified rather than exported.

State Inspection

Chion.get_state — Function
get_state(state, idx=1)

Return a dictionary snapshot for column idx of state. Values are copied into plain Julia containers so callers can inspect state without mutating the state.

source
Chion.print_state — Function
print_state(state, idx=1)

Print a short formatted summary of column idx to standard output. This is a diagnostic convenience wrapper around get_state.

source

Workspaces And Timing

Chion.StepTimingStats — Type
StepTimingStats

Accumulator for profiling major internal stages. Wraps a TimerOutputs.TimerOutput and a per-key item count separate from call count.

source
Chion.add_timing! — Function
add_timing!(stats, key, dt_sec, count=1)

Record dt_sec seconds under key and increment the item count by count.

source
Chion.timing_rows — Function
timing_rows(stats)

Return (rows, total), where rows is a vector of per-stage NamedTuples and total is the sum of all recorded times in seconds.

source
Chion.print_timing_summary — Function
print_timing_summary(io, stats; total_wall_sec=nothing)

Write a human-readable table of accumulated stage timings to io.

source
